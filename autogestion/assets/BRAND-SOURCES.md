# Logos de las ofertas

Recursos locales para identificar productos. Se conserva el nombre accesible en
el título de cada tarjeta; los logos son decorativos y no realizan peticiones externas.

- Sensa: https://www.sensa.com.ar/images/logo_sensa_nav.png
- HBO: https://upload.wikimedia.org/wikipedia/commons/d/de/HBO_logo.svg
  (ficha: https://commons.wikimedia.org/wiki/File:HBO_logo.svg)
- Universal+: https://universalplus.com/assets/logo.svg
  El SVG original blanco se presenta negro mediante CSS sobre las tarjetas claras.
- Fútbol: escudo LPF, como en la web pública USITTEL, en versión transparente:
  https://www.ligaprofesional.ar/wp-content/uploads/2026/01/Logo-solo-2026-derecha-222x300.png
- Mesh, velocidad y STB: símbolos wifi, zap y tv del sprite local existente.

La asignación es exclusivamente visual por identificador/tipo de oferta y no
interviene en detección, precios ni condiciones comerciales.
